# Studio 404 Website

This repo is the Studio 404 website (Next.js, deployed on Vercel from `main`; day-to-day branch `holiday-2026`, fast-forwarded into `main` to deploy).

## Social media lives in a separate folder

**Anything about Instagram, Facebook or Google posts, captions, post graphics, shot lists, the content calendar or GHL Social Planner scheduling belongs in `~/Desktop/STUDIO404-Social Media`, not here.** If André asks about social media in this folder, point him to open that folder in a new session. (The website side of social is only the bio link page, `app/links/page.tsx`.)

If website changes affect social content (prices, mini days, offer wording in `lib/holiday.ts`), mention that captions in the social folder may need the same update.
